# Imagine City — คืนสุดท้ายก่อนสีจะหายไป

เว็บเกม Quiz แบบ Responsive ที่อ้างอิงจากภาพ UI / ภาพประกอบใน `Final Code (2).pdf` (รวมถึงภาพตัวละครใน `Final Code (1).pdf`) และคำถามจาก `Imagine City คืนสุดท้ายก่อนสีจะหายไป (โจทย์ควิซสำหรับน้อง ๆ)(4).pdf`

## วิธีเปิดใน VS Code

1. แตกไฟล์ ZIP ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
2. เปิดโฟลเดอร์ `imagine-city-game` ใน VS Code
3. ติดตั้ง Extension `Live Server` (ถ้ายังไม่มี)
4. คลิกขวา `index.html` → **Open with Live Server**
5. เล่นในคอมพิวเตอร์หรือเปิด Developer Tools → Toggle Device Toolbar เพื่อดูขนาดโทรศัพท์

หากไม่ใช้ Live Server สามารถดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เช่นกัน

## ไฟล์สำคัญ

- `index.html`: โครงสร้างหน้าเว็บ
- `style.css`: รูปแบบ UI ที่ถอดจาก Wireframe (ลายเส้นขาวดำและสีสันตอนจบ)
- `script.js`: เนื้อเรื่อง คำถาม เส้นทาง คะแนน การย้อนกลับ ผลลัพธ์ และเสียงกดปุ่ม
- `assets/`: โลโก้ ภาพฉาก ตัวละคร และบัตรนักเดินทางที่แยกจาก PDF ที่ให้มา

## ระบบเกม

- หน้าปก → บทนำ → คำถามพร้อมภาพประกอบ → ย่านความสนใจ → ด่านทดสอบ → คืนเทศกาล → บัตรนักเดินทาง → ผลลัพธ์
- คำถามให้คะแนน **11 ฉาก** รวมสูงสุด 11 คะแนน (ตอบฉากละ 1 ข้อ)
- มี 5 เส้นทาง ได้แก่ `DGA`, `DGD`, `IGD`, `AFX`, `DEN`
- ตัวเลือกคำตอบสุ่มลำดับใหม่เมื่อเริ่มเกมแต่ละครั้ง และจะคงลำดับเมื่อกดย้อนกลับในรอบนั้น
- ย่านความสนใจใน Chapter 3 แสดง 1 ย่าน หรือ 2 ย่าน หากคะแนนสองอันดับแรกหลังฉาก 2.3 ห่างกันไม่เกิน 1 คะแนน โดยคำตอบด้านอาชีพในย่านไม่เพิ่มคะแนน
- ผลลัพธ์แสดงศาสตร์หลัก และศาสตร์รองด้วยหากคะแนนสองอันดับแรกห่างกันไม่เกิน 1 คะแนน (ถ้าคะแนนเสมอกันใช้คำตอบฉาก 5.2 ช่วยจัดอันดับ)
- หน้าผลลัพธ์แสดงรูปเป็ดพ่อมดที่สอดคล้องกับสาขาจากไฟล์ต้นฉบับ
- หน้าแสดงผล **ไม่แสดงคะแนนตัวเลข** ทั้งศาสตร์หลักและรอง แต่ระบบยังใช้คะแนนเพื่อเลือกผลลัพธ์เหมือนเดิม
- มีทรานซิชันเปลี่ยนหน้าสั้น ๆ ภาพแต่ละฉากมีท่าเคลื่อนไหวแบบนุ่มนวลตามเนื้อเรื่อง และปุ่มคำตอบมีเอฟเฟกต์ยุบ–เด้งพร้อมวงเส้นเมื่อเลือก โดยรองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์
- บัตรนักเดินทางเป็นข้อมูล **ไม่บังคับ** และไม่มีการส่งคำตอบไปยังเซิร์ฟเวอร์ ข้อมูลจะหายเมื่อรีเฟรช
- ปุ่มเปิด/ปิดเสียงด้านบนขวาใช้งานได้ (เสียงสั้นสร้างในเบราว์เซอร์)
- ปุ่ม **พิมพ์ / บันทึก PDF** ใช้เมนูพิมพ์ของเบราว์เซอร์

## จุดแก้ไขเนื้อหา

แก้ใน `script.js`:

- `SCENES`: ชื่อฉาก บรรยาย คำถาม และตัวเลือก 11 ฉาก
- `DISTRICTS`: เนื้อหาย่านทั้ง 5 และรายการอาชีพ
- `TRACKS`: ชื่อผลลัพธ์ คำอธิบาย ภาพตัวละคร และสายอาชีพ

แก้สี ขนาด รูปแบบกรอบ และ Responsive ได้ใน `style.css` โดยไม่ต้องแก้ระบบคะแนน

## หมายเหตุ

- ใช้ฟอนต์ Mali (ภาษาไทย) และ Patrick Hand (ภาษาอังกฤษ) ผ่าน Google Fonts; หากออฟไลน์ เบราว์เซอร์จะใช้ฟอนต์สำรอง
- เกมนี้ทำงานแบบ Front-end ไม่ได้บันทึกข้อมูลผู้เล่นลงฐานข้อมูลหรือส่งข่าวสารอัตโนมัติ
- รูปประกอบใน `assets/` ดึงจาก PDF ต้นฉบับของโปรเจกต์ และชื่อไฟล์ถูกจัดให้ง่ายต่อการแก้ไข
